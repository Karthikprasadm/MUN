# MUNSoc RNSIT - Custom Globe Images

Place your custom images for the 3D globe in this folder!

## Instructions:
1. Name your images **`1.jpg`** through **`30.jpg`**.
2. Save them directly inside this folder (`d:\MUN\assets\globe\`).
3. The website will automatically detect your local files and load them!

*Note: Any missing files (e.g. if you only upload 10 images) will automatically fall back to the premium red-vibe Unsplash images, so the globe never shows broken links.*
